# Panel Cladding WPF UI Test

> **Code moved on 2026-10-28.** This folder keeps the evidence only: the smoke project is in [`tests/Smoke/panel-cladding-wpf-ui`](../../tests/Smoke/panel-cladding-wpf-ui/) (run `.\tests\Run-Regression.ps1 -Name panel-cladding-wpf-ui`). Commands below are historical; see the [regression test layout EXET](../../Project_Exet/261028_EXET_regression-test-layout.md).

This folder contains focused structural and off-screen rendering verification for the non-Eto WPF
Panel Cladding Editor introduced by
`Project_Plan/260812_PLAN_panel-cladding-wpf-ui.md`.

## Run

```powershell
dotnet run --project .\Project_Test\260812_TEST_panel-cladding-wpf-ui\PanelCladdingWpfUiSmoke.csproj -c Debug
dotnet run --project .\Project_Test\260812_TEST_panel-cladding-wpf-ui\PanelCladdingWpfUiSmoke.csproj -c Release
```

The smoke creates a real 4 x 3 `PanelCladdingLayout`, loads it through the production controller and
WPF window, asserts design-critical actions and the custom grid canvas, confirms that the production
assembly does not reference Eto, and renders the UI without opening Rhino or automating Windows.
